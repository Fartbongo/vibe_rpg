# Minimalist RPG

A simple grid-based RPG game built with Python and Pygame.

## How to Play
- Use arrow keys to move the player.
- Fight enemies by moving into their position.
- Reach the treasure to win the game.

## How to Run
1. Install Python 3.10+.
2. Install Pygame: `pip install pygame`.
3. Run the game: `python vibe_rpg.py`.
